19. CONFIRMATION PRIORITY
======================================================================

ImpactまたはLikelihoodがUNKNOWNでも、
順位付けを放棄してはいけません。

各Riskに：

CONFIRMATION_PRIORITY_RANK
PRIORITY_REASON_JA
PRIORITY_DRIVER
DECISION_DEADLINE_FLAG
COMPANY_CONNECTION_STATUS
EVIDENCE_GAP_RESOLVABILITY
MATERIAL_CHANGE_THIS_WEEK

を付与してください。

CONFIRMATION_PRIORITY_RANK：

1..Nの全順序
同順位なし

これはRisk Severity Rankingではありません。

意味は：

「今週、どのRiskから確認を進めると
意思決定に必要な不確実性を最も早く減らせるか」

です。

標準判断順序：

1. 期限または次回重要日程が近い
2. 当社Exposure / Gatewayとの接点が確認されている
3. 未確認事項が判断を変え得る
4. 未確認事項が公開情報等で取得可能
5. 今週Material Changeがあった
6. Evidence更新が近い

同順位が残る場合のみ、
Stable RISK_IDで決定的にTie Breakしてください。

PRIORITY_REASON_JAは、
順位の理由を自然な日本語で1～2文にしてください。

21. DEGRADED MODE
======================================================================

以下を算定してください。

IMPACT_DECIDED_RATIO
LIKELIHOOD_DECIDED_RATIO
TIMING_KNOWN_RATIO
PROXIMITY_DECIDED_RATIO

定義：

IMPACT_DECIDED_RATIO
=
IMPACT_BAND != UNKNOWN の件数 / 全Risk件数

PROXIMITY_DECIDED_RATIO
=
PROXIMITY_CLASS != UNKNOWN の件数 / 全Risk件数

DISPLAY_MODEの判定：

IMPACT_DECIDED_RATIO < 1/3
または
PROXIMITY_DECIDED_RATIO < 1/3

なら：

DISPLAY_MODE = PRIORITY_MODE
DEGRADED_MODE_FLAG = true

それ以外：

DISPLAY_MODE = QUADRANT_MODE
DEGRADED_MODE_FLAG = false


PRIORITY_MODEの意味：

・四象限を主力画面にしない
・確認優先度を主力画面にする
・UNKNOWNを隠さない
・何を確認すれば判定が進むかを前面に出す


QUADRANT_MODEの意味：

・影響度 × 近さを主要比較Viewとして利用可能
・確認優先度も併存
