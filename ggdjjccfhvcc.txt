# 債券先物の仕組みと為替エクスポージャーの評価方法

## 元本・評価損益・当初証拠金・変動証拠金の関係を基礎から解説

対象：外貨建て債券先物（米国債先物など）／日本の経済価値ベース・ソルベンシー規制

### 1. 結論

債券先物とは、将来、一定の条件で債券を売買する契約です。現物債券とは異なり、取引開始時点では債券の購入代金全額を支払いません。その代わりに、一定の証拠金を用意して取引します。

債券先物には、主に4つの金額が登場します。

| 項目          | 役割                    | 為替エクスポージャーとの関係        |
| ----------- | --------------------- | --------------------- |
| 元本          | どれくらいの大きさの債券を取引するかを示す | 原則、直接算入しない            |
| 評価損益        | 先物価格の変動によって発生した利益・損失  | 未決済分や決済後の外貨残高を通じて反映   |
| 当初証拠金       | 将来の損失に備えて預ける担保        | 外貨建ての正味資産であれば算入       |
| 変動証拠金・値洗い差金 | 日々発生する先物の損益を精算するもの    | 決済後に外貨資産・負債として残った額を算入 |

特に重要なのは、元本が大きいことと、同額の為替エクスポージャーを保有していることは別問題だという点です。

債券先物は大きな金利リスクを保有できる一方、為替エクスポージャーは、先物契約から生じる外貨建て資産・負債や、未決済の為替感応度に基づいて評価する必要があります。

通常の米国債先物のように日々の損益が最終決済され、決済金および証拠金が既に為替エクスポージャーに反映されており、先物本体に未決済評価損益が残っていなければ、先物本体から追加的に計上する為替エクスポージャーはゼロとする整理が合理的です。

ただし、これは先物の経済的仕組みから導いた結論です。日本の告示に「債券先物の為替エクスポージャーは常にゼロ」と直接定めた条文があるわけではありません。

## 2. 債券先物とは何か

### 2-1. 現物債券との違い

例えば、米国債を購入する場合を考えます。

現物債券の場合、基本的には購入代金を支払って債券を取得します。

100万ドルの米国債を購入すれば、100万ドル相当の外貨建て資産を保有することになります。

その後、米国債の価格が変われば債券の時価が変動します。また、ドル円相場が変動すれば円換算の資産価値も変わります。

これに対して、債券先物は、将来の債券売買に関する契約です。

例えば「将来、一定の条件で米国債を買う」という契約を結びますが、取引開始時点で購入代金の全額を支払うわけではありません。

取引開始時点では、将来の損失に備えた証拠金を用意します。

したがって、現物債券と債券先物では、同じような債券価格変動リスクを保有していても、実際に保有する外貨建て資産の構成が異なります。

### 2-2. なぜ少額の証拠金で大きな取引ができるのか

債券先物では、取引所や清算機関が売り手と買い手の取引の履行を管理します。

仮に債券先物の元本が10万ドルであっても、10万ドルの現金を最初から用意する必要はありません。

その代わりに、一定の当初証拠金を用意し、その後に発生する損益を日々精算します。

これにより、債券価格が変動した場合にも、損益が長期間累積して決済不能になることを防ぐ仕組みになっています。

米国CME Groupは、先物取引について、毎日の清算価格を用いて損益を計算する仕組みを説明しています。日本のJSCCも上場デリバティブの値洗いを少なくとも1日1回実施し、値洗いに伴う差金等を授受するとしています。

### 2-3. 債券先物は最終的にどうなるのか

債券先物は、主に次の2通りの方法で終了します。

反対売買による決済では、買い建てた先物を売り戻します。例えば、110で買った先物を112で売れば、その価格差に応じた利益が確定します。実際には、それまでの日々の値洗いによって、損益の大部分は既に精算されています。

満期における決済では、商品の契約条件に応じて、現物債券の受渡しまたは現金による最終決済が行われます。

米国債先物には現物受渡し型の商品があり、満期に至って受渡しが行われる場合には、対象となる米国債と代金の受渡しが発生します。

このため、先物を保有している期間と、最終的に現物債券を取得した後とでは、為替エクスポージャーの評価が異なる場合があります。

## 3. 元本・評価損益・証拠金の関係

ここからは、具体的な数字を使って説明します。

米国債先物を1枚買い建てたとします。

以下は仕組みを理解するための仮定です。

| 項目         | 設定        |
| ---------- | --------- |
| 契約上の額面元本   | 100,000ドル |
| 取引開始時の先物価格 | 110       |
| 当初証拠金      | 4,000ドル   |
| ドル円相場      | 150円／ドル   |

### 3-1. 元本とは何か

元本とは、先物取引の規模を決める基準となる金額です。

米国債先物には、1枚当たり額面10万ドルを契約単位とする商品があります。

[image](https://www.google.com/s2/favicons?domain=https://www.cmegroup.com\&sz=32)

cmegroup.com



先物価格が110であれば、額面100に対する価格が110という意味なので、価格換算した契約価額は、

\\[ 100,000\times\frac{110}{100} =110,000\text{ドル} \\]

となります。

ただし、これは11万ドルを支払って債券を購入したという意味ではありません。

保有しているのは、将来の債券売買に関する先物契約です。

この元本10万ドルは、主に先物価格が変動したときに、いくら利益や損失が発生するかを決める基準として機能します。

### 3-2. 評価損益とは何か

債券先物を買い建てた後、先物価格が110から111に上昇したとします。

買い建てているため、価格が上昇すれば利益が発生します。

評価損益は、簡略化すると次の式です。

\\[ G=N\times\frac{P-P_0}{100} \\]

ここで、

- \\(G\\)：取引開始時点からの累積損益
- \\(N\\)：契約上の額面元本
- \\(P_0\\)：取引開始時の先物価格
- \\(P\\)：現在の先物価格

とします。

実際に計算すると、

\\[ G=100,000\times\frac{111-110}{100} =1,000\text{ドル} \\]

となります。

つまり、元本10万ドルの債券先物でも、価格が110から111に上昇したことによる利益は1,000ドルです。

逆に、先物価格が110から109に下落した場合には、

\\[ G=100,000\times\frac{109-110}{100} =-1,000\text{ドル} \\]

となります。

このように、元本は価格変動損益を計算するための基準であり、元本自体が利益や損失になるわけではありません。

### 3-3. 当初証拠金とは何か

当初証拠金は、債券先物の取引を開始するために預ける担保です。

例えば、元本10万ドルの先物を取引するために、4,000ドルの証拠金が必要だったとします。

この場合、4,000ドルを用意することで、10万ドルの額面を基準とする債券先物の価格変動リスクを保有できます。

証拠金は債券の購入代金ではありません。取引に損失が生じたときにも決済できるよう、担保として差し入れるものです。

また、当初証拠金は必ずしも米ドル現金とは限りません。

取引所・清算機関・取引業者の規則に応じて、現金以外の適格担保が認められる場合もあります。

したがって、米国債先物を取引しているからといって、当初証拠金も必ず米ドル建てとは限らないことに注意が必要です。

### 3-4. 変動証拠金・値洗い差金とは何か

債券先物では、原則として毎営業日、先物価格の変化による損益を計算します。

これを「値洗い」といいます。

例えば、次のように価格が推移したとします。

| 日付    | 先物価格  | その日の損益   |
| ----- | ----- | -------- |
| 取引開始日 | 110   | 0ドル      |
| 1日目   | 111   | ＋1,000ドル |
| 2日目   | 109.5 | −1,500ドル |

1日目は1,000ドルの利益が発生します。

2日目は、前日の111から109.5に下落しているので、1,500ドルの損失が発生します。

この日々の損益が、変動証拠金または値洗い差金として授受されます。

ただし、用語には注意が必要です。取引所先物では、損益を現金で最終決済する方式が一般的です。一方、他のデリバティブでは、変動証拠金が損益の最終決済ではなく担保として授受される場合があります。

CMEの先物については日々の値洗い損益が現金決済される方式が説明されています。また、JSCCは上場デリバティブの値洗差金を変動証拠金の概念に含めています。

したがって、「変動証拠金」という言葉が使われていても、それが最終決済された損益なのか、返還義務のある担保なのかを区別する必要があります。

## 4. 取引開始から値洗いまでの資金の動き

ここでは、取引を最も単純化し、当初証拠金4,000ドルと日々の値洗い差金を、同じドル建て口座で管理すると仮定します。

ドル建て口座残高の推移

取引開始

## $4,000

当初証拠金

1日目

## $5,000

利益＋$1,000

2日目

## $3,500

損失−$1,500

単純化した例です。実際には当初証拠金と値洗い決済金が別口座で管理されたり、最低証拠金額を維持するための追加差入れが必要になったりします。

取引開始時点では、4,000ドルを証拠金として預けています。

1日目には、先物価格の上昇によって1,000ドルの利益が発生し、それを受け取ります。

受け取った1,000ドルを同じドル建て口座に残せば、口座残高は5,000ドルになります。

2日目には、先物価格の下落によって1,500ドルの損失が発生し、これを支払います。

したがって、口座残高は3,500ドルになります。

一方、先物の元本10万ドルは変わりません。

ここから分かるのは、元本は変わらなくても、日々の評価損益によって実際の外貨資産残高は変化するということです。

## 5. 評価損益と変動証拠金の関係を数式で表す

より厳密にするため、次の記号を使います。

| 記号                | 意味                     |
| ----------------- | ---------------------- |
| \\(N\\)           | 契約上の額面元本               |
| \\(P_0\\)         | 取引開始時の先物価格             |
| \\(P_t\\)         | t日目の先物価格               |
| \\(G_t\\)         | 取引開始以降の累積損益            |
| \\(\Delta VM_t\\) | t日目の値洗い差金（受取りを正、支払いを負） |
| \\(IM_0\\)        | 当初証拠金                  |

買建てで、ポジション数が途中で変わらない場合、累積損益は、

\\[ \boxed{ G_t=N\frac{P_t-P_0}{100} } \\]

となります。

一方、当日の値洗い差金は、前日の価格からの変化によって決まります。

\\[ \boxed{ \Delta VM_t=N\frac{P_t-P\_{t-1}}{100} } \\]

毎日発生した値洗い差金を合計すると、

\\[ \begin{aligned} \sum\_{i=1}^{t}\Delta VM_i &=\frac{N}{100}\sum\_{i=1}^{t}(P_i-P\_{i-1})\\\ &=\frac{N}{100}(P_t-P_0)\\\ &=G_t \end{aligned} \\]

です。

つまり、

\\[ \boxed{ \text{累積損益} = \text{日々の値洗い差金の累計} } \\]

という関係が成立します。

ただし、ここでいう累計は過去に授受した金額の合計であり、現在残っている変動証拠金の残高と同じとは限りません。

例えば、受け取った利益を円転したり、別口座へ移動したりすれば、ドル建て口座にはその金額が残っていないからです。

## 6. 債券先物の為替エクスポージャーは何によって決まるのか

ここから、経済価値ベースのソルベンシー規制における為替リスクの話につなげます。

### 6-1. そもそも為替エクスポージャーとは

為替エクスポージャーとは、為替相場が変動した場合に、保有する資産や負債の円換算価値がどの程度変化するかを考えるためのポジションです。

例えば、1万ドルの現金を保有しているとします。

ドル円が150円の場合、その円換算価値は、

\\[ 10,000\times150=150\text{万円} \\]

です。

ドル円が120円に下落すると、

\\[ 10,000\times120=120\text{万円} \\]

となります。

つまり、ドル安によって30万円の損失が発生します。

このとき、為替エクスポージャーは1万ドル、基準日の円換算額では150万円です。

### 6-2. 現物米国債の場合

現物米国債を11万ドル保有していれば、為替以外の要因を固定した場合、円換算価値は、

\\[ V\_{\mathrm{JPY}}=110,000S \\]

となります。

ここで \\(S\\) はドル円レート（円／ドル）です。

為替レートに対する感応度は、

\\[ \frac{\partial V\_{\mathrm{JPY}}}{\partial S} =110,000 \\]

です。

したがって、為替エクスポージャーは11万ドルと考えられます。

### 6-3. 債券先物の場合

これに対して、債券先物では、元本10万ドルを支払って現物債券を取得しているわけではありません。

先物価格が110から111に上昇して1,000ドルの利益が発生し、その1,000ドルを日々の値洗いで受け取った場合を考えます。

受け取った1,000ドルがドル建て現金として残っていれば、その部分には為替リスクがあります。

一方、先物の契約元本10万ドルは、そのままドル現金として存在するわけではありません。

このため、元本10万ドルをそのまま為替エクスポージャーとして計上することは、通常の値洗い決済型先物の経済的実態とは整合しません。

ただし、ここで注意が必要です。

先物契約の時価がゼロであることだけを理由に、為替エクスポージャーがゼロと結論づけることはできません。

例えば、為替予約では取引開始時の評価額がゼロでも、大きな為替エクスポージャーを持ち得ます。

債券先物について元本全額を算入しないと考える根拠は、単に時価がゼロであるからではなく、ドル建て債券先物価格を一定とした為替変動だけでは、契約元本全額に相当する円換算損益が発生しないという取引構造にあります。

## 7. 為替エクスポージャーを数式で表す

### 7-1. 基本式

債券先物に関連して、次の記号を定義します。

- \\(IM\_{\mathrm{USD}}\\)：ドル建て当初証拠金に係る正味資産
- \\(VM\_{\mathrm{USD}}\\)：値洗い決済金のうち、現在もドル建て資産・負債として残っている純額
- \\(U\_{\mathrm{USD}}\\)：先物本体に残る未決済評価損益のうち、他の科目に未反映の額

この場合、他のドル資産・負債がなく、証拠金・決済金に対応する返還義務等も適切に控除されているとすると、為替エクスポージャーは、

\\[ \boxed{ E\_{\mathrm{FX}} = IM\_{\mathrm{USD}} + VM\_{\mathrm{USD}} + U\_{\mathrm{USD}} } \\]

と整理できます。

ここで、ユーザーの前提どおり、未決済評価損益がないものとします。

\\[ U\_{\mathrm{USD}}=0 \\]

したがって、

\\[ \boxed{ E\_{\mathrm{FX}} = IM\_{\mathrm{USD}} + VM\_{\mathrm{USD}} } \\]

です。

さらに、当初証拠金と値洗い決済金がすべて既存の為替エクスポージャー計算に反映されていれば、

\\[ \boxed{ E\_{\mathrm{FX}}^{\mathrm{先物本体・追加}}=0 } \\]

となります。

### 7-2. 元本と評価損益を含めた表現

最も単純なケースとして、次の条件を置きます。

1. 当初証拠金を米ドル現金で差し入れる。
2. 日々の値洗い損益は米ドルで最終決済される。
3. 決済された損益はすべてドル建て口座に留保する。
4. 追加差入れ・引出し・円転はない。
5. 未決済の評価損益はゼロである。

この条件では、

\\[ VM\_{\mathrm{USD}}=G_t \\]

であり、

\\[ G_t=N\frac{P_t-P_0}{100} \\]

なので、

\\[ \boxed{ E\_{\mathrm{FX}} = IM\_{\mathrm{USD}} + N\frac{P_t-P_0}{100} } \\]

と表せます。

この式から、元本が為替エクスポージャーにまったく関係しないわけではないことが分かります。

元本が大きいほど、同じ先物価格変動に対して大きな評価損益が発生し、その損益がドル建て資産として蓄積されれば、為替エクスポージャーも大きくなります。

ただし、元本自体を直接算入するのではなく、元本を基準に発生した損益のうち、実際に残っている外貨ポジションを捕捉するという関係です。

なお、この式はあくまで単純化したケースです。決済金を円転した場合や、証拠金を追加差し入れした場合には、実際のドル建て残高を用いる必要があります。

### 7-3. 為替感応度からの検証

先物のドル建て未決済価値を \\(U\\)、外貨建て証拠金等の正味資産を \\(C\\) とします。

これらの円換算価値は、

\\[ V\_{\mathrm{JPY}}=S(C+U) \\]

です。

ドル建て先物価格および外貨建て資産・負債の数量を固定して為替レートだけを変化させると、

\\[ \boxed{ \frac{\partial V\_{\mathrm{JPY}}}{\partial S} =C+U } \\]

です。

日々の値洗い決済により \\(U=0\\) であれば、

\\[ \boxed{ \frac{\partial V\_{\mathrm{JPY}}}{\partial S} =C } \\]

となります。

つまり、為替感応度から考えても、基準日時点で存在する外貨建ての正味資産・負債が基本的な評価対象となります。

ただし、この検証は債券先物価格を固定した為替単独ショックについてのものです。金利と為替が同時に変化する場合や、将来の受渡し・決済に伴う資金調達リスクまで評価しているわけではありません。

## 8. 具体的なケースによる比較

元本10万ドル、当初証拠金4,000ドル、値洗い利益1,000ドルの先物を例に、為替エクスポージャーを比較します。

### ケースA：当初証拠金も値洗い決済金もドル建て

当初証拠金4,000ドルを差し入れ、値洗い利益1,000ドルを受け取り、どちらもドル建て資産として残っている場合です。

\\[ E\_{\mathrm{FX}}=4,000+1,000 =\boxed{5,000\text{ドル}} \\]

このとき、先物本体の追加計上額はゼロです。

### ケースB：当初証拠金は円建て、値洗い決済金はドル建て

当初証拠金は円資産であり、値洗い利益1,000ドルだけがドル現金として残っている場合です。

\\[ E\_{\mathrm{FX}}=0+1,000 =\boxed{1,000\text{ドル}} \\]

この場合、当初証拠金に起因するドルの為替エクスポージャーはありません。

### ケースC：当初証拠金はドル建て、値洗い利益は円転済み

当初証拠金4,000ドルはドル資産として残っていますが、値洗い利益1,000ドルは既に円転している場合です。

\\[ E\_{\mathrm{FX}}=4,000+0 =\boxed{4,000\text{ドル}} \\]

過去に1,000ドルの利益が発生したこと自体は、その1,000ドルが現在も為替リスクにさらされていることを意味しません。

### ケースD：当初証拠金も値洗い決済金も円建て

当初証拠金は円建てで、値洗い差金も円で決済され、ドル建て未収未払金も残っていない場合です。

この場合、ドル建て先物本体に別途未決済価値がなければ、

\\[ E\_{\mathrm{FX}}=\boxed{0} \\]

と整理できます。

以上をまとめると、次のようになります。

| ケース | 当初証拠金 | 値洗い利益の残存通貨 | ドルの為替エクスポージャー |
| --- | ----- | ---------- | ------------- |
| A   | ドル    | ドル         | 5,000ドル       |
| B   | 円     | ドル         | 1,000ドル       |
| C   | ドル    | 円          | 4,000ドル       |
| D   | 円     | 円          | 0ドル           |

いずれのケースでも、契約額面元本は10万ドルです。

つまり、契約元本が同じでも、証拠金や決済金の通貨・保有状況によって為替エクスポージャーは異なります。

## 9. 日本の経済価値ベース・ソルベンシー規制との関係

### 9-1. 告示第121条の基本構造

日本の経済価値ベースのソルベンシー規制では、為替リスクの計算に当たり、通貨ごとの「正味オープン・ポジション」を求めます。

第1の柱告示第121条は、主な構成要素として次を規定しています。

| 規定   | 対象              | 債券先物との関係                     |
| ---- | --------------- | ---------------------------- |
| 第1号イ | 正味スポット・ポジション    | BS上の外貨建て証拠金・現預金・未収未払金等       |
| 第1号ロ | 正味フォワード・ポジション   | 先物為替取引の将来受払額等。通常の債券先物とは区別が必要 |
| 第1号ヘ | その他オフ・バランスの為替損益 | BSに反映されていない為替損益等の該当性を検討      |

原典：金融庁「第1の柱告示」第121条。

[image](https://www.google.com/s2/favicons?domain=https://www.fsa.go.jp\&sz=32)

fsa.go.jp



ここで重要なのは、第1号ロが「先物取引一般」ではなく、「先物為替取引」を対象としていることです。

米国債先物は、米ドル建ての債券価格を対象とする先物取引であり、ドルと円を将来交換する為替先物取引とは異なります。

そのため、債券先物の元本全額を第1号ロの正味フォワード・ポジションに算入することは、文言上、直ちには導かれません。

### 9-2. 証拠金の取扱い

外貨建ての当初証拠金や値洗い決済金が、経済価値ベースのBSにおいて資産・負債として計上されていれば、第121条第1号イの正味スポット・ポジションとの関係で評価するのが自然です。

この場合に重要なのは、取引業者等に差し入れた証拠金が、会計上・法的にどのような資産として認識されているかです。

例えば、ドル現金を担保として差し入れ、同額のドル建て返還請求権を保有している場合には、その請求権の為替感応度を評価します。

一方、担保の授受に対応する同一通貨の負債等が存在する場合には、それも考慮する必要があります。

単に「差し入れた証拠金の額」を無条件で加算するのではなく、正味の外貨建て資産・負債として把握することが重要です。

### 9-3. IAISのICSとの整合性

IAISのICS Level 2においても、L2-230で通貨ごとのNet Open Positionを計算することとされています。

その構成要素には、Net Spot Position、Net Forward Position、その他外貨建ての損益を表す項目が含まれています。

ICS-Level-1-and-Level-2-texts.pdf



国内告示第121条と同様に、為替エクスポージャーを、保有資産・負債や取引契約の通貨別ポジションから把握する構造です。

ただし、ICSにおいても、債券先物について、証拠金を計上済みなら先物本体の為替エクスポージャーは必ずゼロになる、という個別具体的な規定まで確認できたわけではありません。

したがって、国内告示・ICSのいずれについても、取引の経済実態と第121条等の構成要素との対応関係を説明する必要があります。

## 10. 実務上、特に注意すべき事項

これまでの整理を実際のリスク計測に適用する場合、次の事項が重要です。

第一に、変動証拠金が損益の最終決済なのか、担保の授受なのかを確認する必要があります。

最終決済であれば、先物本体の未決済損益が解消され、その損益は決済後の現金等に反映されます。

これに対して、変動証拠金が担保として扱われる契約では、デリバティブ本体の評価額と担保に係る資産・負債が併存する可能性があります。

この場合、デリバティブ本体の評価額を無条件にゼロと扱うことはできません。

第二に、評価損益と決済金を重複して算入してはいけません。

例えば、累積評価益1,000ドルを受け取り、ドル建て現金に反映済みであれば、さらに同じ1,000ドルを評価益として加算すると、為替エクスポージャーを過大評価してしまいます。

第三に、証拠金の通貨を確認する必要があります。

米国債先物の損益はドル建ての先物価格を基準に計算されますが、取引業者との契約や口座管理によって、担保・決済金の通貨や処理が異なる場合があります。

証拠金が円建て資産であるなら、それ自体にはドルの為替エクスポージャーはありません。

第四に、基準日と値洗い・決済のタイミングを一致させる必要があります。

例えば、基準日の先物評価損益が確定していても、実際の差金決済が翌営業日となる場合には、基準日時点で未収金または未払金が存在する可能性があります。

この部分は、未決済損益として残るのか、未収未払金に振り替えられているのかを確認する必要があります。

第五に、為替リスクと金利リスクを混同しないことが重要です。

債券先物の為替エクスポージャーがゼロであっても、金利リスクがゼロになるわけではありません。

むしろ、債券先物は少額の資金で大きな金利感応度を保有できる商品です。

例えば、先物本体の為替エクスポージャーがゼロであっても、米国金利が上昇して債券先物価格が下落すれば、損失が発生します。

そのため、為替リスク上は元本を直接算入しない一方、金利リスク上は原資産の金利感応度や先物の価格感応度を適切に反映する必要があります。

第六に、将来の受渡しや証拠金の追加差入れに伴う流動性リスクは別途管理すべきです。

満期に現物受渡しが発生する場合には、債券の受取りと決済代金の支払いが生じます。また、金利変動によって大きな損失が発生すれば、追加の値洗い差金を支払う必要があります。

これらは、基準日時点の為替エクスポージャーが小さいことだけでは把握できないリスクです。

したがって、為替エクスポージャーを小さく評価することと、債券先物に起因するすべてのリスクが小さいことは、明確に区別する必要があります。

## 11. 最終整理

債券先物は、少額の証拠金を用いて、一定の元本に対応する債券価格変動リスクを保有する商品です。

取引開始時には債券の購入代金全額を支払う必要はありませんが、先物価格の変動によって利益または損失が発生します。

通常の取引所先物では、この損益を毎日値洗いし、差金決済を行います。

その結果、損益が最終決済されれば、先物本体の未決済評価損益は原則として解消され、決済後の現金や証拠金等に反映されます。

したがって、為替エクスポージャーを評価する際には、契約元本ではなく、実際に残っている外貨建ての正味資産・負債や、未決済の為替感応度を捕捉することが基本となります。

一般化すると、

\\[ \boxed{ \begin{aligned} E\_{\mathrm{FX}} ={}&\text{外貨建て証拠金等の正味資産}\\\ &+\text{外貨建て決済金の正味残高}\\\ &+\text{未計上の先物評価損益等} \end{aligned} } \\]

となります。

未決済評価損益がなく、外貨建ての当初証拠金・変動証拠金・決済済み損益が既存の計算で適切に反映されていれば、

\\[ \boxed{ \text{債券先物本体の追加的な為替エクスポージャー}=0 } \\]

とする整理が、経済的には最も合理的と考えられます。

ただし、この結論は、通常の値洗い決済型先物を前提としたものです。変動証拠金の法的性質、BSへの計上方法、通貨、決済時点、現物受渡しの有無によって適用範囲が変わります。

日本の経済価値ベース規制における実務上の結論としては、次の3点に集約できます。

1. 債券先物の元本は、金利リスク等の計測に重要な金額であるが、為替エクスポージャーとしてそのまま計上するものではない。
2. 債券先物の評価損益は、未決済であればその為替感応度を、決済済みであれば決済後に残る外貨建て資産・負債を通じて捕捉する。
3. 当初証拠金および変動証拠金に関する外貨ポジションが既に適切に計上され、先物本体に別途の未計上ポジションがなければ、先物本体の追加計上は不要と整理できる。

現時点で最も重要な未確認事項は、対象の債券先物について、日々の値洗い差金が損益の最終決済として処理され、その結果が基準日の外貨建てBSに漏れなく反映されているかという点です。

この条件を確認できれば、先物本体の追加的な為替エクスポージャーをゼロとする論理の確度を高めることができます。
